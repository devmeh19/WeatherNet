# 🌦️ Android Weather App

A beautiful and minimal weather application for Android that fetches real-time weather data for any city using the OpenWeatherMap API. Built using modern Android development practices.

---



---

## 🧰 Features

- 🔍 Search weather by city name
- 📍 Get weather for your current location (using GPS)
- 🌡️ Display temperature, humidity, pressure, and wind speed
- ⛅ Display weather conditions with appropriate icons
- 🌙 Dark mode support
- 🌐 Real-time API integration with OpenWeatherMap
- ⚠️ Input validation and error handling

---

## 🛠️ Tech Stack

- **Language:** Kotlin / Java
- **Architecture:** MVVM / MVP (as applicable)
- **API Integration:** Retrofit / Volley
- **JSON Parsing:** GSON / Moshi
- **Location Services:** FusedLocationProvider
- **UI Components:** RecyclerView, ConstraintLayout, CardView
- **Image Loading:** Glide / Coil
- **Dependency Injection:** Hilt / Koin (if used)
- **Build Tool:** Gradle
